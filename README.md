# AI-103 course: Northpine Basecamp

Code for the AI-103 full course by **AI, Actually**. You build Northpine Basecamp, the AI system of a fictional outdoor-gear shop, and learn every skill in the exam *AI-103: Developing AI Apps and Agents on Azure*.

## Two folders

| Folder | Use it when |
| --- | --- |
| [`starter-kit/`](starter-kit/) | You follow the course. Start here and build the app module by module |
| [`ready-app/`](ready-app/) | You want to see or run the finished app with all the code |

## Stuck in a module?

Each module has a Git tag: `m01`, `m02` and so on. A tag holds the starter kit as it should look at the end of that module.

```
git checkout m05
```

## Everything is fictional

Northpine Outfitters, its brands, customers, orders and prices are invented for this course.
